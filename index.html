I'm a machine learning researcher working on data-efficient training - subset selection, gradient sketching, and tensor methods that make models learn more from less. Alongside research, I write and make videos that unpack the ideas behind modern AI from first principles. I also run Frontier ML Nepal, a community for people exploring machine learning in Nepal.

I'm currently open to freelance and consulting work in machine learning: research prototyping, model optimization and data-efficient training, and technical writing or explainer content. If you're building something I can help with, get in touch.
